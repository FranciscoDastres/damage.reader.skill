# Alcance y procedencia

Código independiente. No se incluyen archivos, tablas ni fragmentos de DrDamage, ni recursos redistribuidos del cliente.

El destino del proyecto es WoW Forever. La build y las capacidades del cliente deben comprobarse mediante el informe integrado; el nombre del servidor o producto no demuestra por sí mismo la disponibilidad de una API.

No hay automatización de acciones, procesos externos en el juego ni lectura de memoria. No se registran eventos restringidos del combat log ni se evaden valores secretos. Se utiliza la información que el cliente permite leer; cuando está protegida en combate se conserva una estimación anterior marcada con * al final, siempre que no se haya invalidado la identidad del botón.

El addon se distribuye gratuitamente con código visible. No incluye publicidad, solicitudes de donaciones ni telemetría.

[Política pública de addons de Blizzard](https://us.forums.blizzard.com/en/wow/t/ui-add-on-development-policy/24534). Esta referencia no equivale a una aprobación individual del proyecto ni certifica compatibilidad con una build concreta.
